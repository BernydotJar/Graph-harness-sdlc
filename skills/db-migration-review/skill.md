# DB Migration Review Skill

Use this skill before schema, migration, seed, or database command work.

## Inputs

- active feature spec
- schema/migration diff
- `docs/database-change-policy.md`

## Checklist

- schema change has explicit human approval
- migration behavior is reviewed
- rollback or remediation is documented
- seed behavior is environment-aware
- destructive commands are approved
- production timing constraints are known
