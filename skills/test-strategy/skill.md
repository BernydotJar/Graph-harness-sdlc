# Test Strategy Skill

Use this skill when defining or reviewing verification for a feature.

## Inputs

- active feature spec
- implementation plan
- `docs/verification.md`
- mode-specific criteria

## Checklist

- happy path
- negative path
- invalid input
- empty state
- permission/visibility boundary
- i18n copy keys when applicable
- regression cases
- build or static checks when applicable

Tests should match feature risk and mode.
