# Spec Authoring Skill

Use this skill when creating or patching feature specs.

## Inputs

- `feature_list.json`
- `templates/feature/requirements.md`
- `templates/feature/design.md`
- `templates/feature/tasks.md`
- relevant docs under `docs/`

## Output

- `specs/<feature-id>/requirements.md`
- `specs/<feature-id>/design.md`
- `specs/<feature-id>/tasks.md`

## Checklist

- requirements are testable
- non-goals are explicit
- file boundaries are declared
- verification commands are included
- MVP and SHIP criteria are addressed
- i18n/accessibility requirements are included for user-facing features
- implementation has not started
