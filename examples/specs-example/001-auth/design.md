# 001-auth Design

## Approach

Use the project's approved auth/session library to request and validate email sign-in links.

## Files You May Read

- auth configuration
- user/session model
- active feature spec

## Files You May Touch

- auth route/controller
- sign-in form
- auth tests
- i18n copy files

## Files You Must Not Touch

- unrelated features
- database migrations without approval
- environment files
- secrets

## Context7 Checkpoints

- auth/session library docs
- framework route handler docs

## Verification Plan

- run unit tests
- run auth integration tests
- run `./init.sh`
