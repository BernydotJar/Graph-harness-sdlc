# 002-search Requirements

## Summary

Add a simple bounded search results flow.

## Mode

MVP

## Acceptance Criteria

- [ ] User can submit a search query.
- [ ] Results are limited.
- [ ] Empty state is readable.
- [ ] Error state is safe.
- [ ] English and Spanish copy exists.

## Non-Goals

- Advanced filters
- Ranking algorithms
- Saved searches

## MVP Criteria

- bounded scope
- basic tests
- verification evidence
- known gaps documented
