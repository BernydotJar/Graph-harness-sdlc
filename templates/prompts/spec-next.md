# Prompt: spec-next

Create the next feature spec only.

Read:

- `feature_list.json`
- relevant docs
- templates under `templates/feature/`

Touch:

- `specs/<feature-id>/requirements.md`
- `specs/<feature-id>/design.md`
- `specs/<feature-id>/tasks.md`
- `feature_list.json`
- progress files

Stop when the feature is `spec_ready`.
