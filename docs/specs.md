# Specs

Every feature spec lives under:

```text
specs/<feature-id>/
  requirements.md
  design.md
  tasks.md
```

## requirements.md

Defines user needs, acceptance criteria, mode criteria, i18n needs, and non-goals.

## design.md

Defines the implementation approach, file boundaries, data contracts, dependencies, risks, and verification plan.

## tasks.md

Defines ordered implementation tasks, verification tasks, review tasks, and stop conditions.

## Approval

A spec with status `spec_ready` is not approved for implementation.

Implementation begins only after a human moves the feature to `approved`.
