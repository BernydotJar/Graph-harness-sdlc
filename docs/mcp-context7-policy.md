# Context7 MCP Policy

Use Context7 or current documentation checkpoints for external framework/API work.

Required documentation checkpoint examples:

- Next.js routing, rendering, server actions, middleware, caching, or deployment behavior
- React APIs, hooks, compiler behavior, or concurrent rendering behavior
- Prisma schema, migrations, client APIs, or transaction behavior
- PostgreSQL SQL behavior, indexes, constraints, and query plans
- Tailwind configuration, class behavior, or framework integration
- Vitest configuration, mocking, coverage, or environment behavior
- OpenCode command behavior or agent integration
- auth/session libraries
- deployment/runtime-specific APIs

Do not use Context7 for simple local bookkeeping:

- updating `progress/current.md`
- appending `progress/history.md`
- changing feature status
- markdown-only edits

When a checkpoint affects a spec or implementation decision, record:

- source
- version or date when available
- decision impact
- files affected
