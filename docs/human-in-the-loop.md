# Human In The Loop

The harness keeps humans in control of high-impact decisions.

## Human Approval Required

- approving a spec
- changing feature scope
- adding dependencies
- changing schemas
- running migrations
- running destructive commands
- changing secrets or environment variables
- closing a rejected review
- production release

## Human Input Required

- ambiguous product behavior
- unclear data ownership
- conflicting priorities
- missing access credentials
- blocked external service or docs access

## Agent Responsibilities

Agents must:

- state the needed decision
- explain the impact
- offer the smallest safe next step
- avoid irreversible action while waiting

## Human Responsibilities

Humans provide:

- explicit approval
- product decisions
- access to external systems when required
- release decisions
